# بوابة الطالب | جامعة مرشدي (Morshidi University)

بوابة أكاديمية متكاملة لجامعة مرشدي (Morshidi University) تخدم طلبة بكالوريوس الذكاء الاصطناعي (كلية تكنولوجيا المعلومات - الخطة 12).
تم بناء المنصة بتصميم عربي أصيل (RTL-First)، نمط نهاري مريح للعين (Light Mode)، وواجهات عصرية فائقة السلاسة.

---

## 🌟 مميزات البوابة

1. **الخطة الدراسية الرسمية (خطة 12):**
   - 132 ساعة معتمدة مقسمة وفق متطلبات الجامعة والكلية والتخصص الإجبارية والاختيارية والمساندة.
   - 68 مساقاً معتمداً مع احتساب دقيق للمتطلبات السابقة وحالات المواد (منجزة، مسجلة، متاحة، غير متاحة، تحتاج مراجعة).

2. **طرح 3 شُعَب لكل مساق (204 شُعَب):**
   - جدول محاضرات منظم دون أي تعارض زمني في المواد الأساسية والمختبرات.
   - توزيع المحاضرات النظرية بين (ح ث خ) و (ن ر)، والمختبرات يوم واحد أسبوعياً في فترات ما بعد الظهر.

3. **سلة التسجيل الذكية والسحب والإضافة:**
   - فحص فوري للمتطلبات السابقة ومطابقة الساعات والحد الأدنى والأعلى للفصل الدراسي.
   - فحص تلقائي وتنبيه فوري عند وجود أي تعارض في أوقات المحاضرات.

4. **كشف العلامات والمعدل التراكمي (النظام المئوي):**
   - احتساب المعدل الفصلي والتراكمي من 100%.
   - حاسبة ومحاكي تقدير المعدل المستقبلي.

5. **مرشدي الذكي (Morshidi AI):**
   - تكامل مدمج ومباشر مع منصة مرشدي للذكاء الاصطناعي: [morshidi.vercel.app](https://morshidi.vercel.app/).

6. **تصميم Light Mode راقٍ:**
   - خلفيات عاجية وبيضاء ناصعة، خط تجوالي عربي أنيق، وظلال ناعمة تعكس الهوية الأكاديمية الرفيعة.
