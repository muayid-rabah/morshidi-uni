# بوابة جامعة مرشدي

بوابة RTL مبنية بـ React وVite، مع API داخلي بـ Fastify وSQLite. قاعدة البيانات هي مصدر التشغيل؛ ملفات `server/seed-data` تُستخدم لتهيئتها أول مرة فقط، ولا تُنشر كملفات عامة.

## التشغيل

يتطلب Node.js 24 أو أحدث.

```powershell
npm ci
npm run dev:server
npm run dev
```

للبناء والتحقق:

```powershell
npm run test:server
npm run build
npm start
```

## الإعداد

انسخ أسماء المتغيرات من `.env.example` إلى بيئة الخادم والبوابة، وأدخل القيم من لوحة الاستضافة. لا تضع مفاتيح الخدمة في واجهة المتصفح. مفتاح `VITE_SUPABASE_PUBLISHABLE_KEY` وحده مخصص للواجهة.

- مصادقة الطلاب عبر Supabase Auth، والبريد بصيغة الرقم الجامعي في نطاق الجامعة.
- `UNI_ADMIN_USER_IDS` قائمة UUIDs لمستخدمي الإدارة الموثوقين.
- أحداث التغييرات موقعة بـ HMAC وتُرسل إلى `UNI_WEBHOOK_URL`، مع سجل قابل لإعادة القراءة عبر `/v1/events`.
- في الاستضافة، وجّه `UNI_DATABASE_PATH` إلى تخزين دائم؛ القرص الافتراضي المؤقت لا يحفظ SQLite بعد إعادة التشغيل.

## البيانات

بيانات التهيئة الحالية هي fixtures موجودة في المستودع وليست اتصالًا رسميًا بسجل الجامعة. يجب استيراد السجلات الرسمية والتحقق من حسابات Supabase قبل استخدامها لطلاب حقيقيين. لا توجد كلمات مرور افتراضية أو حسابات قابلة للتبديل داخل الواجهة.
